# HCL-GenAI-Training

This repository contains my work from AI and Machine Learning training, including structured notes, practical exercises, coding assignments, Retrieval-Augmented Generation (RAG) tasks, and agent-based projects. It serves as a centralized place to organize all my learning materials and track progress throughout the program.

The repository is organized week-wise so that each section reflects the concepts and hands-on tasks covered during the training. The work includes foundational machine learning tasks, NLP-based sentiment analysis, CNN-based image classification, RAG pipelines, retrieval systems, and simple AI agents with memory, tool usage, and web-based data extraction.
